# 成电课程播放助手

一个仅适配 `resource.uestc.edu.cn` 指定课程播放页的 Chrome / Edge Manifest V3 扩展。它用于改善真实观看课程视频时的操作体验，不伪造或直接修改平台学习记录。

这是个人项目，并非电子科技大学或课程平台的官方扩展。

## 已实现功能

- 原生视频倍速：0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×。
- 视频自然结束后，只有在当前课程的只读目录元数据确认“紧邻的下一学习内容”为已发布视频时，才在页面前台显示 5 秒倒计时；可立即进入下一节、取消本次，或关闭连续播放。
- 优先使用 XGPlayer 结束层的“下一个学习内容”按钮；没有时才使用当前课程区域底部的“下一个”按钮。
- 切换后以播放器上方的章节标题核对目录，而不依赖可能滞后的目录高亮或保持不变的 URL；还会确认视频地址已切换且元数据就绪，再启动续播流程。即使 XGPlayer 此时还没有填好最终时长，也会等待播放器初始化、必要时触发中央播放控件，并在浏览器拒绝有声自动播放时尝试一次静音起播。
- 目录记录含有两个资源编号时会同时核对，避免已切到正确视频却被误判；若等待超时，弹窗会说明是资源身份、播放器装载还是页面状态未通过检查。
- 快捷键：`Alt + Shift + .` 提速、`Alt + Shift + ,` 降速、`Alt + Shift + N` 开关连续播放。
- 倍速和连续播放开关只保存到浏览器本地。

连续播放默认关闭，需由用户在扩展弹窗中手动开启。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载已解压的扩展程序”。
4. 下载并解压本仓库，选择解压后包含 `manifest.json` 的文件夹。
5. 刷新课程播放页后，点击浏览器工具栏中的“成电课程播放助手”。

支持的首版页面路径为：

```text
https://resource.uestc.edu.cn/learn/course/detail/spoc/courseWare/*
```

## 使用方式

1. 在课程播放页打开扩展弹窗，选定播放速度。
2. 打开“连续播放”。
3. 当前视频自然播放结束后，页面会出现倒计时浮层。
4. 倒计时结束时，扩展仅点击平台已提供的下一节入口；新内容被确认是视频后才调用浏览器的正常播放能力。

Chrome 可能阻止没有可信用户手势的有声自动播放。扩展会先尝试静音起播；如果恢复声音会导致播放器暂停，则保持静音并提示点击播放器恢复声音。若静音起播也被阻止，扩展会保留在新视频页面并提示手动点击播放，不会伪造可信用户手势或绕过浏览器策略。

## 安全边界

本扩展明确不会：

- 伪造观看时长、播放进度或完成状态；
- 绕过验证码、人脸、签到、前台检测、测验或平台弹窗；
- 后台静音挂机、自动答题、自动提交内容；
- 收集账号密码，或将学习数据上传到任何服务。

遇到互动页、文档/音频、平台弹窗、最后一节、无法从目录确认类型的内容、不可识别的播放器，或原生视频全屏时，连续播放会停止并给出提示，而不会尝试跳过页面流程。

目录判断结果只在页面内短暂缓存，不会写入平台数据或上传到其他服务；如果目录接口无法返回，扩展仅在可见目录能明确识别当前项和下一项均为视频时才使用该降级判断。

## 文件说明

- `manifest.json`：MV3 清单，仅注册目标课程页面。
- `content.js` / `content.css`：视频识别、倍速、倒计时与页面级下一节操作。
- `background.js`：本地设置、页面状态和一次性自动播放许可。
- `popup.html` / `popup.css` / `popup.js`：扩展弹窗界面。
- `tests/background-smoke.test.js`：后台消息与一次性续播许可的无浏览器 smoke test。
- `tests/content-transition.test.js`：下一节资源身份识别与超时诊断的无浏览器测试。

## 本地验证

在安装扩展前可运行：

```powershell
node --check content.js
node --check background.js
node --test tests\*.test.js
```
